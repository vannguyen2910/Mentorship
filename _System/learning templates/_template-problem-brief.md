## 3. Coherent Actions

<!--
DIRECTIONS, NOT DESIGNS. An action says where effort goes and where it stops.
"Confirm every state change to the customer as it happens" is a direction.
"Send a push notification when the ETA slips" is a design, and design belongs to the
next stage, where alternatives get compared and the choice gets tested.

Coordinated, not a list: each action should be stronger because the others exist.
If any could be deleted without weakening the rest, it was a task, not part of a strategy.

Every action carries its riskiest assumption. It tells the next stage what to test first,
