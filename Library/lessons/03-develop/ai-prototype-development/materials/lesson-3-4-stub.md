# Lesson 4: Present & Publish — Git & GitHub for Non-Technical Designers

*(Objectives locked in from the coaching plan — full lesson content to follow; can draw directly on `Library/guides/publish-your-work-git-github-for-non-technical-designers`, which already covers the publishing half in full.)*

**Learning Objectives**
- Frame the finished prototype's story for its audience — the methodology and decisions behind it, not just the finished pixels *(moved here from Lesson 3)*
- Understand the local-vs-published mental model: local folder is the draft, GitHub is the published version, push is the publish button
- Set up GitHub Desktop and connect it to the same project folder organised in Lesson 1, then make a first publish
- Publish the stitched prototype to a live, self-updating URL — independent of any design tool account

**Planned structure:** presenting the work (the new opener — student arrives with the three sentences drafted as Lesson 3 homework; coach it into a one-minute framing of process and decisions) → KNOW (local-vs-published mental model) → Setup & Connect → First Publish → Make It Live → simulate one mistake and recover from it → solo practice rep *(first thing to cut for time)* → SHOW (teach-back).

**What the student brings:** the stitched prototype with its triage list worked through, the three-sentence draft from Lesson 3's homework, and a GitHub account with GitHub Desktop already installed — install friction shouldn't eat session time.

**Only the presentation coaching is genuinely new content to draft.** The git/github material is a pointer to the existing guide, not a rewrite.
