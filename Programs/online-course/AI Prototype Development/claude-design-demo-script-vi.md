# Kịch bản Demo Trực Tiếp Claude Design (5 phút)

**Chuẩn bị trước khi demo:** file Figma mở sẵn, panel token, component, và một template frame sẵn sàng để click qua; file .fig export sẵn để upload; đã đăng nhập vào org cần demo trên claude.ai/design.

---

**Mở đầu (không tính giờ)**
> "Xin chào các bạn, mình là Winnie Nguyễn, hiện tại mình đang là UX product design educator cho khoá học này. Trong bài học này mình sẽ hướng dẫn các bạn cách set up design system bằng Claude Design."

**0:00–0:45 — Xem nhanh file Figma**
> "Trước khi đưa vào Claude, mình show nhanh cái mình có trong file Figma này. Đây là design token, màu sắc, spacing, type scale, tất cả định nghĩa dưới dạng variable. Đây là component library, button, card, input. Và đây là một template dựng từ các component đó, ví dụ trang dashboard này."

[Click qua: panel token → panel component → 1 template frame]

**0:45–1:15 — Điền thông tin + upload**
> "Giờ mình đưa cái này vào Claude Design. Mô tả ngắn gọn về sản phẩm để Claude có context..."

[Gõ tên công ty/mô tả ngắn]

> "Giờ đến file, được parse ngay trên trình duyệt, không upload lên server nào cả."

[Kéo file .fig vào, để nó xử lý]

**1:15–2:15 — Xem lại design system vừa tạo**
> "Claude vừa extract ra một design system từ file này: bảng màu, typography, các component chính, và pattern về layout."

[Click qua 2-3 phần vừa extract, chọn phần nào giống rõ nhất với cái vừa xem trong Figma]

**2:15–3:45 — Test prompt (điểm nhấn của demo)**
> "Giờ thử cho Claude làm việc thật."

[Gõ: "Create a landing page for [product]."]

[Để Claude generate trên màn hình, vừa chạy vừa narrate]

> "Để ý kết quả không hề generic, nó tự động dùng đúng màu thương hiệu, đúng type scale, đúng style button của mình."

**3:45–4:30 — Publish**
> "Bật toggle 'Published' lên. Từ giờ mọi project mới trong org này sẽ tự động dùng design system này, không ai phải setup lại nữa."

[Bật Published]

**4:30–5:00 — Kết**
> "Tóm lại: upload Figma một lần, Claude extract ra design system, mọi project sau này thừa hưởng luôn. Nếu sau này file Figma thay đổi, mình chỉ cần quay lại đây và remix, chuyện đó mất năm giây thôi, không nằm trong phần demo hôm nay."

---

**Phương án dự phòng:** nếu upload live bị chậm, chuẩn bị sẵn một org thứ hai đã có sẵn cùng file đó để chuyển qua dùng.
