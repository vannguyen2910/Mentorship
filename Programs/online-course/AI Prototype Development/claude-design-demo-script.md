# Claude Design Live Demo Script (5 min)

**Setup before going live:** Figma file open with tokens, components, and a template frame ready to click through; the .fig export ready to upload; logged into the target org in claude.ai/design.

---

**Intro (untimed)**
> "Hi everyone, I'm Winnie Nguyen, UX product design educator for this course. In this lesson, I'll walk you through how to set up a design system using Claude Design."

**0:00–0:45 — Quick Figma walkthrough**
> "Before I bring this into Claude, let me quickly show what's actually in this Figma file. Here are our design tokens — colors, spacing, type scale, all defined as variables. Here's our component library — buttons, cards, inputs. And here's a template built from those components, like this dashboard page."

[Click through: tokens panel → components panel → 1 template frame]

**0:45–1:15 — Fill in + upload**
> "Now let's bring this into Claude Design. Quick description of the product so Claude has context..."

[Type company name/blurb]

> "Now the file itself — parsed locally in the browser, never uploaded to a server."

[Drag .fig file in, let it process]

**1:15–2:15 — Review the generated system**
> "Claude just extracted a design system from this: our color palette, typography, core components, and layout patterns."

[Click through 2–3 extracted pieces — pick ones that clearly match what we just saw in Figma]

**2:15–3:45 — Test prompt (the payoff)**
> "Let's put it to work."

[Type: "Create a landing page for [product]."]

[Let it generate on screen — narrate while it runs]

> "Notice it's not generic — it's using our brand colors, our type scale, our button style, automatically."

**3:45–4:30 — Publish**
> "Flip 'Published' on. Every new project in this org now starts from this system — no one has to set this up again."

[Toggle Published]

**4:30–5:00 — Close**
> "So: one Figma upload, Claude extracts the system, and every future project inherits it. If the Figma file changes later, we just come back and remix — that's a five-second follow-up, not part of today's demo."

---

**Fallback:** if the live upload is slow, have a second org pre-populated with the same file ready to switch to.
