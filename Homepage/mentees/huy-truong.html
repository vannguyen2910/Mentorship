Programme overview

This is a 4-session, weekly masterclass that moves Huy from prototyping screen-by-screen in whatever tool is in front of him, to running a systematic, pattern-first method for AI-assisted prototyping — define the system once (component inventory + interaction pattern), then let AI build and scale from it. The programme isn't portfolio-specific: the same method applies to any real prototype, client work included. The vehicle here is real: one polished, stitched multi-screen prototype (for Huy, a portfolio case study), organised in a clean project structure from day one and published to a live URL via Git/GitHub by the final session.

Tools for this engagement: Huy's primary AI coding tool is Claude Code, taught end-to-end as the single workflow. (The sessions below are written tool-agnostically — swap this line per mentee to reuse the plan.)

Learning objectives

  • Define the interaction pattern layer — which screens exist, how they connect, what triggers each transition — and save it as a reference file alongside the component inventory
  • Scope a build, then build the case study screens by pointing the AI coding tool at the saved component inventory and interaction pattern files — prompting only for what's specific to each screen, not re-explaining the system every time
  • Apply the three edit modes — chat for structural changes, targeted feedback for one element, direct manual nudges

Success check

  • All (or nearly all) case study screens working in the browser, reviewed for consistency against the component inventory
